# Agenda Nusantara

Aplikasi mobile catatan tugas harian berbasis Flutter dengan penyimpanan lokal SQLite. Mendukung kategorisasi tugas (penting/biasa), statistik harian, grafik mingguan, dan autentikasi offline.
